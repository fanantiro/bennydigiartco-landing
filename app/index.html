Application purpose

BennyDigiArtCo Content Publisher helps Benny Digital Art Co manage the business's own original content across its Etsy and Pinterest workflows. The application converts business-owned Etsy listing information and product imagery into draft Pinterest content, presents that content for human review, and publishes only the Pins selected and approved by the operator.

How the workflow operates

  1. Prepare: The operator imports original product images and listing information owned by Benny Digital Art Co.
  2. Create drafts: The application creates alternative Pin layouts and accompanying titles, descriptions and destination links.
  3. Human review: The operator previews the results, edits them where necessary, and individually selects the Pins approved for publishing.
  4. Choose destination and timing: The operator chooses the Pinterest Board and publishing schedule for approved content.
  5. Publish through Pinterest: The application uses Pinterest's official OAuth flow and API to create the approved Pins on the connected business account.
  6. Record status: The application retains local publishing status and may retrieve Pin performance information for the operator's own reporting.

Pinterest API use

The application is designed to request only the Pinterest permissions needed for its stated workflow, including reading Boards, reading Pins and creating Pins. OAuth access and refresh tokens are used to authorize API calls. The application does not collect Pinterest passwords, verification codes or session cookies, and it does not bypass Pinterest's authorization flow.

User control and publishing safeguards

The operator remains in control throughout the workflow. Draft generation does not publish content. Each Pin must pass through the application's review and selection queue before scheduling or publishing. The operator can remove items from the queue, edit content, stop scheduled work and revoke the Pinterest connection.

Intended access

The current application is for the business owner's use with Benny Digital Art Co's own Pinterest presence. It is not a public social network, consumer login service, data broker, or tool for collecting credentials from other Pinterest users.

Business relationship

Benny Digital Art Co is the business identity behind both the BennyDigiArtCo Etsy shop and BennyDigiArtCo Content Publisher. This website provides the public business, application and privacy information for that same operation.
