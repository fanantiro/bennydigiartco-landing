Pin Workflow

A private Windows desktop application used only by Benny Digital Art to prepare and publish organic content to our own Pinterest Business account.

Application purpose

Benny Digital Art Pin Workflow supports our internal Etsy-to-Pinterest content workflow. When an Etsy product listing is created as a draft, the application prepares Pinterest-ready content drafts locally. These drafts may include product images, suggested Pin titles, descriptions, recommended Boards and proposed publishing dates.

Creating an Etsy draft does not publish anything to Pinterest. After the Etsy listing is manually published and a public Etsy product URL becomes available, proposed Pins become available for review.

How the workflow operates

  1. Prepare: The operator imports original product images and listing information owned by Benny Digital Art.
  2. Create drafts: The application creates alternative Pin layouts and accompanying titles, descriptions and destination links.
  3. Human review: The account owner individually reviews and selects each Pin, confirming its image, title, description and destination URL.
  4. Choose destination and timing: The operator confirms the Pinterest Board and proposed publishing date for each approved Pin.
  5. Publish through Pinterest: The application uses Pinterest's official OAuth flow and API to create the approved Pins on the connected business account.
  6. Record status: The application retains local publishing status and may retrieve Pin performance information for the operator's own reporting.

Pinterest API use

The initial Pinterest API integration is limited to reading our own Boards, creating approved organic Pins, reading our own published Pins, and reading basic performance data for our own Pins. OAuth access and refresh tokens authorize these API calls.

The application connects only to Benny Digital Art's own Pinterest Business account through Pinterest OAuth 2.0. It does not collect Pinterest passwords, verification codes or session cookies, and it does not bypass Pinterest's authorization flow.

User control and publishing safeguards

The operator remains in control throughout the workflow. Draft generation does not publish content. Each Pin must pass through the application's review and selection queue before scheduling or publishing. The application does not automatically bulk-publish Pins without individual approval. The operator can remove items from the queue, edit content, stop scheduled work and revoke the Pinterest connection.

Intended access

The current application is for the business owner's use with Benny Digital Art's own Pinterest presence. It is not a public social network, consumer login service, data broker, or tool for collecting credentials from other Pinterest users.

It does not automate follows, saves, comments, messages or other engagement actions, and it does not scrape Pinterest.

Initial version boundaries

The initial version covers organic Pin creation, scheduling and basic reporting only. Paid advertising management, ad campaign creation, public multi-user access and automated engagement are not included.
